Good questions.

Is this the app?+

No. Tokly is a Mac desktop app. This fictional demo cannot read your files or open an editor.

What does Tokly track?+

File activity, Git metadata and your notes. Not hours worked or personal productivity.

What about Windows and Linux?+

macOS comes first. No confirmed Windows or Linux release date.
