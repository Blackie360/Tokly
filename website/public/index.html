A FEW SMALL DETAILS

Before you
settle in.

Is this a web app or a desktop app?+

Tokly is a local-first desktop app for macOS. This page is a website with an illustrative preview. The preview cannot scan your folders or access your projects.

Do I need an account?+

No account is required to use the desktop app. Downloading the early builds requires access to the private GitHub repository.

What does Tokly track?+

Tokly records file activity and Git metadata for projects in approved workspace folders. It keeps next-step notes locally. Activity and commits describe repository changes, not hours worked or personal productivity.

Does it work on Windows or Linux?+

The current focus is macOS. Windows and Linux are planned, but there is no confirmed release date.
