Applications

Copies made while one of these apps is frontmost are not remembered. One app name or bundle identifier per line. This is best effort; prefer pasteboard types where an app offers one.

Pasteboard types

Copies carrying any of these types are not remembered. Transient and concealed copies (nspasteboard.org) are always skipped.

Regular expressions

Text matching any of these patterns is not remembered. One pattern per line.

Turn off:

Temporarily ignore all new copies. You can also ⌥-click the menu icon, or ⌥⇧-click it to ignore only the next copy.

Clearing:

Removes all unpinned items before quitting.

Clearing the history also empties the current clipboard.

Check every:

How often the clipboard is checked for changes. Default: 0.5.
